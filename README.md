# Bamise Alabi — Professional Portfolio

GitHub Pages source for Bamise Alabi's professional website.

## Publish
1. Upload all files/folders in this package to the root of `obsidian77/obsidian77.github.io`.
2. In GitHub: **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.
5. Visit `https://obsidian77.github.io` after GitHub completes deployment.

## Custom domain later
When `bamisealabi.com` is purchased, add it in **Settings → Pages → Custom domain**. DNS records should only be configured after the domain is owned and the exact GitHub Pages instructions are confirmed.

## Privacy / content review
The first version deliberately avoids detailed operational postings, personal contact details, and sensitive military information. Review all public content before adding further detail.
